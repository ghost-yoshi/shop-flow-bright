# Shop Flow Bright

fait une plateforme de vente d'arctivles en ligne cohérent du debut à la fin. on doit pouvoir toggle entre dark/light mode.
l'UI doit etre non géneriques tu éviteras les flex et grid trop génerique pour ton rendu
je veux des couleurs claires reflettant la vente pas un truc orienté neon/Gaming
les données doivent etre fetch depuis des routes django centralise les routes de fetch backend au lieu de les éparpilllé sur chaque page. centralise egalement les données fictives liées au preview dans un fichier précis qui aappele les données foctives si et seulment si le backend n'a pas pu etre fetch(à des fin de previews)
